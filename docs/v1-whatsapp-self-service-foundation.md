# WhatsApp self-service foundation

This is unmounted source on the actual `0056_v1_comment_operator` base. Both real-enable flags remain false. It does not establish Meta compatibility, deploy a webhook/worker hook, send a message, or satisfy the V07 live acceptance gate.

The approved contract is [v1-whatsapp-self-service-contract.md](v1-whatsapp-self-service-contract.md). The additive `0057_v1_whatsapp_self_service` migration creates five tables. It binds current owner/session insertions, immutable account choices and authorization provenance, one-way provider step claims, one recipient binding and an exact immutable canonical outbound association. The native API, queue service and UI follow separately. Migration SQL has only been rendered offline; actual PostgreSQL direct-SQL negatives/races are pending the serialized database slot.

All new evidence rows have a server-assigned `provider` or `synthetic_fixture` classification where applicable. This field is never accepted from a public command. Illustrative transport data cannot make delivery confirmation true. Immutable generation provenance holds verified grants and expiry; old manual credentials remain unknown. The strict debug-token/granular-scope/expiry schemas are conservative documentary compatibility assumptions, not observed provider-wire proof. Unknown or absent expiry is not treated as permanent.

The new transport uses a fixed `graph.facebook.com` authority and explicit v26 routes, public DNS pinning, TLS hostname validation, bounded JSON and deadlines. It does not use proxy discovery, redirect following, automatic request retries, HTTP client request logging or raw provider error bodies. Four outstanding sockets is a local ceiling; a timed-out request retains an unknown effect and must not be automatically retried. Pagination rebuilds the fixed phone route from a bounded cursor and never follows a provider-supplied URL. The UI SDK is unavailable when the configured embedded app secret disagrees with the existing global webhook secret, encryption is unusable, or required operator configuration is absent.
