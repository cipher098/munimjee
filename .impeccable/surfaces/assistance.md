# Assisted onboarding extension

Mode: Operate. This precise task extends the existing native commerce workspace;
commerce.css is the visual authority. No replacement palette, typography or
system files. The first viewport should identify the current business, its
existing membership role/onboarding lead and the next concrete action.

Use a business list plus one selected-business work area, stacked at390px.
Show real local readiness and honest external blockers, not a completion score
or decorative dashboard metrics. Owner assignment uses existing members only
and does not grant access. No provider/customer data, raw JSON, technical IDs,
credentials, invented live checks or support impersonation in the interface.

Important states: no memberships, unassigned/eligible/unavailable lead, readonly
role, pending command recovery, stale version, lost response/reload, business
selection races, unavailable workspace and latched identity/session end. Native
keyboard controls,44px targets, focus-visible and readable long names are part of
the incumbent world. Final proof must use actual0050 migrations and mounted
native sessions/API in desktop/mobile Chromium; mock/pure proof is separate.
